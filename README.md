# Project 4

## Foundation Resume

This single-page resume uses the instructor-provided Foundation for Sites 6.8.0
starter files. The page adapts resume content from Project 3 to Foundation's
responsive grid, menu, callout, card, and label components.

## Project Structure

- `index.html`: Semantic resume content and Foundation component markup
- `css/foundation.css`: Instructor-provided Foundation framework
- `css/app.css`: Original project styles
- `js/vendor/`: Instructor-provided Foundation dependencies
- `js/app.js`: Foundation initialization
- `media/`: Resume images, audio, and validation badges

The linked readable Foundation stylesheet omits two nonstandard
`text-rendering` declarations and one obsolete Internet Explorer media query
from the starter file so it passes current W3C CSS validation. The original
minified distribution remains unchanged for reference.
